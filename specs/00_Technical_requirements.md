## Overview:

We are building a SaaS application for an edtech named "VedaAI". The main purpose is to just have one feature build here in this web app, so no authentication is required, no database is required. Everything could be done in memory. Just the feature mainly has to be built with the working functionallity as priority.

Tech Stack: 

Architecture - (monorepo)
- Frontend: Next + TypeScript + Tailwind + Figma File reference provided (necessary and strict).
- DB - No db, no auth, everything maintained in-memory
- Backend: TypeScript
- package manager - Bun
- Socket.io for realtime updates

The code written should be clean, standard, maintainable and easy to understand and manage.
Proper comments should be written whereever required.



> Standard practices must be followed everywhere in the code.

> For each sub-feature request, first the backend needs to be built once backend built and tested, then frontend work should be started.

> The ui must be designed strictly as per the figma design provided.

 


**Any doubt or ambiguity while building a sub feature must be asked and resolved before writing the code to avoid further confusions.**
